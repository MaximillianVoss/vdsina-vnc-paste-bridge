# Лицензия

Для собственного кода проекта лицензия на использование, изменение или распространение не предоставлена (`UNLICENSED`). Публичная доступность исходников сама по себе не означает предоставление такой лицензии.

Сторонние исходники noVNC и QEMU не включены в репозиторий и архив расширения. Инструмент подготовки тестов может скачать их по публичным URL с проверкой SHA-256. На эти файлы распространяются лицензии и уведомления их правообладателей; сведения об источниках находятся в `tests/fixtures/*/SOURCE.safe.json`.
