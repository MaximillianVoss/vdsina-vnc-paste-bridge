# Контракт VNC Paste Bridge 1.1.0

Интерфейс 1.1.0 использует существующий транспорт 1.0.5. Локальная подготовка, отправка браузером и подтверждённый сервером результат — разные состояния.

## Пакет

Exact keys: `schema`, `text`, `sha256`, `utf8_bytes`, `code_points`, `batch_size`, `character_delay_ms`, `batch_delay_ms`, `newline_mode`.

| Поле | Условие |
|---|---|
| `schema` | `vnc-paste-packet/v1` |
| `text` | Печатный ASCII, максимум 32768 UTF-8 байт |
| `sha256` | Нижний регистр hex SHA-256 исходного UTF-8 |
| `utf8_bytes`, `code_points` | Целые значения, пересчитанные по тексту |
| `batch_size` | 1..256, по умолчанию 256 |
| `character_delay_ms` | 8..100, по умолчанию 12 |
| `batch_delay_ms` | 80..2000, по умолчанию 120 |
| `newline_mode` | `reject` или явно выбранный `enter` |

CR, Tab и остальные управляющие символы запрещены. LF допускается только в `enter` и означает нажатие Enter; финальный LF исходного файла сохраняется. Собственный финальный Enter очередь не добавляет.

## Расширение

Работает только на `https://cp.vdsina.ru/static/novnc/start.html`. До ввода проверяются целевой сервер, соединение, источник страницы, закреплённые SHA-256 шести same-origin исходников и функции клавиатуры. Gate не отправляет пробные символы. Его неудачный результат кэшируется до обновления страницы.

Каждый символ отправляется через публичный canvas как `KeyboardEvent` с `key=ASCII`, `code=Unidentified`, нулевыми числовыми кодами. Для A–Z и US Shift-пунктуации отдельные ShiftLeft down/up обрамляют символ; отпускание выполняется синхронно в `finally`. Штатный burst-handler не вызывается; private RFB instance, CDP и собственный WebSocket не используются.

Пауза адаптера 4 мс дополняет паузу очереди после каждого символа. Проверки цели/поколения соединения сохраняются на всём протяжении передачи. Stop, timeout, смена сервера, reconnect или reload не возобновляют очередь. Предельная расчётная длительность — 10 минут. Enter запускается отдельным явным действием после новой проверки.

`browser-sent` означает отправку событий браузером; `uncertain` требует проверки серверного состояния до повтора. Ни одно из этих состояний не является квитанцией получения. US-раскладка и CapsLock требуют отдельной живой проверки; модель QEMU в тестах не устанавливает версию или настройки VPS.

## Connection и API

Файл подключения имеет exact keys `schema`, `base_url`, `token`; schema — `vnc-paste-connection/v1`. URL — `http://127.0.0.1:<порт>` без пути или завершающего `/`. Токен используется в Authorization, не сохраняется расширением и не публикуется.

API разрешает только авторизованные GET `/v1/packet` и `/v1/health`, имеет точную проверку Host, не разрешает CORS, не выполняет текст и не имеет записывающих методов. Расширение получает пакет после ручного импорта connection, проверяет его и показывает предпросмотр. Автоматической передачи и фонового polling нет.
