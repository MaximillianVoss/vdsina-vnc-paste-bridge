# Руководство пользователя — VDSina VNC Paste Bridge 1.1.1

Расширение помогает ввести длинную команду в VNC-консоль VDSina: передаёт символы с паузами и показывает ход передачи. Для обычной однострочной команды ввод текста и нажатие Enter — два отдельных действия.

## Установка и обновление

1. Распакуйте архив расширения в постоянную папку. Не удаляйте её после установки.
2. Откройте `edge://extensions` в Edge или `chrome://extensions` в Chrome и включите режим разработчика.
3. Выберите «Загрузить распакованное расширение» и укажите папку `extension` из архива.
4. В панели VDSina откройте VNC нужного сервера. В этой вкладке появится панель «Вставка в VNC».

Панель работает только на странице `https://cp.vdsina.ru/static/novnc/start.html`. На списке серверов и других сайтах она не появляется. Значок расширения не заменяет открытие VNC.

При обновлении замените файлы в установленной папке, нажмите Reload / «Перезагрузить» у расширения в списке расширений и обновите вкладку VNC. Проверьте номер **1.1.1** в панели. Обновляйте страницу после окончания передачи.

## Первый пример: одна команда

Сначала войдите в серверную консоль и дождитесь приглашения командной оболочки. На экране не должно быть запроса пароля, открытого редактора или незавершённой команды. Проверьте нужную VPS по названию и IP; используйте английскую US-раскладку в гостевой системе и выключенный CapsLock.

1. В поле «Текст ASCII» вставьте **одну строку без переноса в конце**:

   ```sh
   printf 'Hello, VNC!'
   ```

2. Нажмите **«Проверить»**. Сверьте показанные название VPS и IP с нужным сервером. Эта кнопка проверяет текст и соединение, но ничего не вводит в консоль.
3. Нажмите **«Отправить текст» один раз**. Дождитесь окончания передачи. Пока идёт очередь, не печатайте вручную в консоли и не переключайте сервер.
4. Посмотрите на строку **в самой консоли**: она должна точно совпасть с примером. На этом этапе команда ещё не должна выполняться.
5. Снова нажмите **«Проверить»**, сверив сервер, затем **«Отдельный Enter» один раз**.
6. Убедитесь, что сервер вывел `Hello, VNC!`. Пример не добавляет перевод строки, поэтому следующее приглашение оболочки может появиться сразу после `!`.

После передачи прежняя проверка сбрасывается. Новая проверка перед Enter заново подтверждает текущее соединение. **Не нажимайте повторно «Отправить текст», чтобы включить Enter:** это повторно введёт команду.

«Передано браузером» и заполненный индикатор означают, что браузер отправил события клавиатуры. Получение и выполнение подтверждаются ответом сервера. Для важной длинной передачи проверьте ожидаемый результат на сервере: например, длину и контрольную сумму полученного файла.

## Что означают элементы панели

| Элемент | Для чего нужен |
|---|---|
| Текущее соединение | Название сервера, IP и состояние проверки. Перед каждым действием убедитесь, что это нужная VPS. |
| Текст ASCII | Точный текст для ввода. Счётчик показывает объём; исправление текста отменяет прежнюю проверку. |
| Проверить | Проверяет текст, параметры и соединение; показывает объём, число частей и SHA-256. Ничего не вводит. |
| Отправить текст | Вводит проверенный текст. Для однострочного режима Enter не добавляется. |
| Стоп | Останавливает оставшуюся очередь. Уже введённые символы не удаляются и не отзываются. |
| Отдельный Enter | Нажимает Enter в консоли и может выполнить находящуюся там команду. Требует свежей проверки. |
| Очистить | Очищает только поле расширения. Строка в серверной консоли остаётся прежней. |
| Импортировать файл | Загружает текстовый файл или `packet.json` в поле для просмотра и проверки. Не отправляет его автоматически. |
| − / + в заголовке | Сворачивает или разворачивает панель. Сворачивание не останавливает передачу. |
| Параметры и SHA-256 | Открывает настройки скорости, режим переносов строк и импорт из локального API. |

**Почему кнопка недоступна:** «Отправить текст» требует непустого допустимого текста, успешной свежей проверки и, для LF, отдельного согласия. «Отдельный Enter» требует свежей проверки соединения. «Стоп» доступен только во время передачи. Поле и большинство настроек блокируются, пока работает очередь. После изменения текста, параметров или завершения действия нажмите «Проверить» заново.

## Какой текст можно передавать

Поддерживаются **латинские буквы, цифры, пробелы и обычные печатные знаки ASCII**. Кириллица, другие символы Unicode, Tab, CR и Windows-переносы CRLF не поддерживаются. Общий предел текста — 32768 байт; в этом наборе символов один символ занимает один байт.

Для обычных команд оставьте режим **«Переносы строк LF: Запретить — по умолчанию»** и передавайте одну строку без завершающего переноса. Длинная строка может визуально переноситься в поле или консоли — это не обязательно символ LF.

### Многострочный ввод — для опытных пользователей

Режим **«Каждый LF отправить как Enter»** превращает каждый перенос LF в нажатие Enter. После проверки потребуется отметить «Разрешаю Enter для каждого LF в этом тексте».

**Каждая строка может выполниться во время передачи. Завершающий LF в файле тоже отправляется и может выполнить последнюю строку.** Дополнительного финального Enter расширение не создаёт. Перед запуском изучите весь текст и убедитесь, что он подходит для текущей оболочки; содержимое `.py` само по себе не запускается как Python-файл.

## Файлы и настройки

Для простого импорта сохраните файл в **UTF-8 без BOM**. BOM — служебная метка в начале файла; файл с ней будет отклонён. Проверьте отсутствие Tab, кириллицы и CRLF, а для однострочного режима — любого перевода строки, включая последний. Расширение не исправляет эти символы молча.

`packet.json` — заранее подготовленный пакет с текстом, настройками и контрольной суммой. Импортируйте его через **«Импортировать файл»**, затем просмотрите текст и нажмите «Проверить». Самостоятельно редактировать поля JSON не требуется; пакет можно подготовить по [инструкции CLI](../CLI.md).

| Настройка | Значение по умолчанию | Значение для пользователя |
|---|---|---|
| Пакет | 256 символов | Размер части: число символов между паузами очереди; допустимо 1–256. Это не установленный предел консоли VDSina. |
| Символ, мс | 12 мс | Пауза между символами; допустимо 8–100 мс. |
| Пакет, мс | 120 мс | Дополнительная пауза между частями; допустимо 80–2000 мс. |

Начните со значений по умолчанию. «Паузы очереди ≈» — расчёт пауз, а не обещанное время завершения: обработка клавиш и работа браузера добавляют время. Очередь с расчётной длительностью свыше 10 минут отклоняется.

**SHA-256** — контрольная сумма текста, помогающая заметить его изменение. При импорте пакета расширение проверяет её автоматически; вручную считать её для обычной вставки не нужно. Эта сумма сама по себе не подтверждает получение сервером.

### Локальный API — необязательный способ импорта

Этот вариант нужен, если вы готовите пакеты через CLI. Обычной вставке текста API не требуется.

Запустите локальный мост по [CLI.md](../CLI.md), затем выберите созданный **`connection.json`** в разделе **«Импорт из локального API»**. Это файл подключения, а не пакет с командой; в обычное поле импорта его выбирать не нужно. Мост должен работать на том же компьютере, что и браузер.

`connection.json` содержит действующий токен доступа: не публикуйте его и не включайте в скриншоты. После перезапуска моста импортируйте новый файл подключения. Полученный из API текст также нужно просмотреть, проверить и отправить вручную.

## Если что-то пошло не так

| Ситуация | Что сделать |
|---|---|
| Панели нет или версия старая | Проверьте, что расширение включено и открыта именно VDSina VNC. Нажмите Reload у расширения и обновите вкладку VNC. Разверните панель, если виден только заголовок. |
| «Отправить текст» или Enter недоступны | Прочитайте сообщение состояния, исправьте указанную причину и нажмите «Проверить». После передачи для Enter нужна ещё одна проверка; повторять отправку текста не нужно. |
| Ошибка ASCII, CR/CRLF, Tab или BOM | Исправьте исходный текст или сохраните файл как UTF-8 без BOM, с LF только в явно разрешённом режиме. Не заменяйте незнакомые символы вслепую в команде. |
| Показан другой сервер | Не отправляйте текст. Откройте VNC нужной VPS и повторите проверку; сверяйте название и IP. |
| Знаки или регистр исказились | Не нажимайте Enter для испорченной строки. Проверьте английскую US-раскладку гостевой системы и CapsLock; сначала разберите и очистите частичный ввод в самой консоли. |
| Разрыв связи, timeout, «Результат неизвестен» или нажат «Стоп» | Очередь автоматически не продолжится. Осмотрите консоль и фактический результат на сервере. Не повторяйте команду вслепую: часть ввода могла дойти, а команда — уже выполниться. |
| Длинный текст отклонён | Проверьте предел 32768 байт и расчётный лимит 10 минут. Подготовьте меньшие осмысленные команды с самостоятельной проверкой результата; не дробите исполняемый код произвольно. |
| Не прошла проверка исходников сайта или клавиатуры | Передача заблокирована, потому что сайт мог измениться. Не обходите проверку и не отключайте её. Проверьте наличие обновления расширения или сообщите разработчику текст ошибки. |

При неожиданном результате сначала установите, что уже произошло на сервере. «Очистить» не очищает консоль, а «Стоп» не отменяет уже выполненные команды.

## Что подтверждено проверками

Код и интерфейс проверяются на локальном стенде. Это не является пользовательским исследованием или подтверждением доставки на конкретную VPS. Для своей операции проверяйте реальный ответ сервера; технические форматы описаны в [CONTRACT.md](../CONTRACT.md).
